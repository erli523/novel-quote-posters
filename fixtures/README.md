# 自写虚构测试材料

mist_letters.txt 为本项目编写的三章虚构样本，人物和语录均为虚构，不引用真实作品。样本按项目 MIT 许可公开，用于定位、归属、生图和排版测试。无用户小说或个人照片。

林澈外貌原文明示：27 岁、黑色短发、左眉尾浅疤、深蓝现代风衣。其他外貌细节必须标设计选择。

dialogue_cases.txt 也是本项目自写虚构样本，包含别名、代词、后置归属、多轮对白、未明确说话人、名字提及、近似人名、未加引号独白与正文中的恶意指令。配套 expected 数据是作者定义的预期分类，不是外部人工金标准；application_analysis 是当前应用端的待审提案，不能代替真实人工批准或代表一般小说的准确率。
