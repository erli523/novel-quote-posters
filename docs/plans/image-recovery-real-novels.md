# 生图故障修复与真实整书测试契约

日期：2026-11-23（Asia/Shanghai）。依据用户新增指示：解决反复生图失败，寻找真实完整小说并测试，继续开发。承接 V1 既有原句、人工审阅和公开白名单边界。

本轮优先定位应用原生图像请求实际路由；只检查必要配置元数据与无副作用路由，不提取或使用存储凭据，不通过非官方脚本重放 ChatGPT 令牌，不静默启用付费 API/第三方生图。当前 ChatGPT 登录模式已确认；若本地文字转发未提供图片路由，则以可回退、仅项目生效的官方 provider 配置修复，记录生效状态，仍须真实成功生成、取得图片后才能宣布修复。配置修改前新增的一次用户要求的原生复测仍立即 404，当时累计保守占用 3/10；配置修改后的首次真实验证见迭代 16，当前累计 4/10、剩余 6。后续仅在运行时/通道确有改变后，在总额 10 内明确调整未用分项再验证，失败留存、不清零。

完整小说优先使用公版中文作品：阿Q正传、儒林外史、红楼梦。保留下载原件、来源/镜像版本、字节大小与 SHA-256、PG 标识和许可证；正文提取若发生，保存原件到规范正文的转换映射。文本只在本地测试，公开仓库默认只发来源清单、代码及脱敏统计，不重发整书或新增用户私有素材。

完整性须核对实际章回序列、开头/结尾、文件截断和全量索引/窗口/候选；不得把下载到 END 标记等同内容质量无误，也不得把全量机器处理冒充全书语义阅读。完整输入、处理覆盖、人物/原句语义抽查分别记录。应用端先读完整阿Q正文，再逐章建立候选和归属；长篇先完成全量结构/性能测试，语义覆盖如未读完明确未完成。最终仍由用户人工批准。

验收关联 AC-101/102/103/106/201/202/203/205/206/305/308/309。原始证据保留 data/public-domain、runs 和 evidence；关键节点经精确白名单同步公开 GitHub。工具调用失败、格式不兼容、性能超限或章节不齐先保留诊断并修复/换可核对版本，不以节选代替完整小说。
