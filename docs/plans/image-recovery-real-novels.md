# 生图故障修复与真实整书测试契约

日期：2026-11-23（Asia/Shanghai）。依据用户新增指示：解决反复生图失败，寻找真实完整小说并测试，继续开发。承接 V1 既有原句、人工审阅和公开白名单边界。

本轮优先定位应用原生图像请求实际路由；只检查必要配置元数据与无副作用路由，不提取或使用存储凭据，不通过非官方脚本重放 ChatGPT 令牌，不静默启用付费 API/第三方生图。当前 ChatGPT 登录模式已确认；若本地文字转发未提供图片路由，则以可回退、仅项目生效的官方 provider 配置修复，记录生效状态，仍须真实成功生成、取得图片后才能宣布修复。当前已新增一次用户要求的原生复测仍立即 404，累计保守占用 3/10；后续最多在总额 10 内明确调整未用分项再复测，失败留存、不清零。

完整小说优先使用公版中文作品：阿Q正传、儒林外史、红楼梦。保留下载原件、来源/镜像版本、字节大小与 SHA-256、PG 标识和许可证；正文提取若发生，保存原件到规范正文的转换映射。文本只在本地测试，公开仓库默认只发来源清单、代码及脱敏统计，不重发整书或新增用户私有素材。

完整性须核对实际章回序列、开头/结尾、文件截断和全量索引/窗口/候选；不得把下载到 END 标记等同内容质量无误，也不得把全量机器处理冒充全书语义阅读。完整输入、处理覆盖、人物/原句语义抽查分别记录。应用端先读完整阿Q正文，再逐章建立候选和归属；长篇先完成全量结构/性能测试，语义覆盖如未读完明确未完成。最终仍由用户人工批准。

验收关联 AC-101/102/103/106/201/202/203/205/206/305/308/309。原始证据保留 data/public-domain、runs 和 evidence；关键节点经精确白名单同步公开 GitHub。工具调用失败、格式不兼容、性能超限或章节不齐先保留诊断并修复/换可核对版本，不以节选代替完整小说。

执行补充：真实输入暴露全角缩进漏章、正文假回目及重复回目，纳入 ingest-2 修复，保留 ingest-1 按记录版本核验。正文不重写，重复整章不被静默删除；显式预期章回序列不匹配即拒绝。Gutenberg 与维基文库的本地素材准备仅做可追溯文本提取，不扩展用户输入格式/外传权限，不以方框或错误引号为由按记忆补文。镜像《儒林外史》未通过完整性；校对版阿Q用于继续阅读，红楼梦旧版先保留压力测试和转录警告。

发布复核另发现迭代 12 的四份文档在 Git LF 规范化后与原 CRLF 工作文件清单哈希不符，纳入同轮修复：旧清单/失败保留，发布纠正清单，公开检查对含 CR 的文本直接拒绝。不得用 CI 成功掩盖公开字节不一致。

迭代 14：应用端实际阅读维基文库版本全部四个哈希窗口，保存逐窗摘要、人物证据、易错归属与候选提案，再用确定性坐标核验和重复导入验证，不能把 AI 判断算作人工真值。真实文本及提案继续私有，公开仅数量、问题与通用改动。整书候选多，增加只显示明确选中候选的原句审核材料；完整候选仍保留，筛选不授予批准，不缩小图文/整组审核范围。只选审核页必须显式配合 quotes-only，零个选中候选给出明确反馈；模拟回归检查局部审核、过期上下文和未选项不被顺带批准。主生图预算不变，无新生图调用；原生通道等待运行时真实重载后验证。
