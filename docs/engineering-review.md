# 工程审查与待决策项（初稿历史记录）

日期：2026-11-22；规范版本：0.1-draft。审查范围：将提案 1.1 转换为可执行 harness 契约与验收标准。本轮仅完成文档草拟与静态一致性检查，未开发、未生图、未创建远程仓库、未运行产品验收。所有 P0—P3 实施关口均未执行。

## 主要结论（可转交主对话）

1. harness 必须留下“任务契约 → 执行 → 检查 → 保存证据 → 修复/回归 → 里程碑同步”的证据链。代理入口保持简短，规范正文放 rules，验收编号放 acceptance；不能靠一份成功叙述代替可打开的资产和检查输出。
2. 原句连续逐字匹配可以确定性核验；说话人归属需要上下文和人工审核。AI 的评分、归属判断、语义去重与人物相似度都只能辅助，不能写成零误差保证。最终具名台词逐条人工批准。
3. V1 是应用端协调，本地脚本做确定性处理。真实调用、参考图编辑、持久文件交接、排字与下载解压须实测；工具存在不等于文件链路已通。手工导入可作为明确披露的可操作流程，不可称为自动完成。
4. P2 最低为独立基准肖像之外的 3 张真实人物底图合成成品，至少 2 套风格且同人物至少出现 2 张；P3 另验同一句同人物的六风格实际图与逐对视觉差异。占位布局不能计数，复用同图裁三张不能算三次真实底图结果。
5. 全文覆盖分别核算“已索引/已处理/语义抽查”，边界与末章有证据。不能把章节数齐全当作模型已找全精彩语录。
6. 恢复幂等与变更失效必须实测：改字不默认重生；换角色、人物版本或来源后旧审核不能继续有效。未知生图返回先对账，不能承诺外部调用 exactly-once。
7. 公开 GitHub 采用精确路径与哈希白名单，原文、上下文、真实档案、私有日志、图片元数据与压缩包均需检查。公开只放自写虚构样本和获准资产，不能为复现公开整本书。文档本身也须发布前脱敏。
8. 本轮只起草公开 P0 契约/P1 原文/P2 真实生图/P3 图集关口，不创建或发布仓库，不把本轮文档工作声明成产品关口通过。

## 对提案的关键收紧与取舍

| 提案要求/风险 | 本规范处理 | 取舍/限制 |
| --- | --- | --- |
| 可追溯原句与说话人 | AC-102 与 AC-103 独立；原句 hash/坐标/连续切片，说话人保存上下文与人工审阅 | 人工审核增加时间，但归属不能靠字符串匹配担保 |
| 修改台词 | 原句与显示文字分开，改写双端标记并失效旧审核 | 不支持把润色默认为原文 |
| 六套不同样式 | AC-301 实际图、15 对差异矩阵；AC-302 覆盖六套句长压力 | 视觉差异仍属人工判断 |
| 至少三张真实生图 | 独立基准图不计入，三张独立底图结果与成品成链 | 这是建议采用的严格计数口径，需在开发契约确认预算 |
| 长小说 | 源映射、窗口并集、块调用、边界哨兵和末章检查 | 不承诺抽取召回完整性 |
| 应用端生图 | 能力与交接实测，不编造外部调用接口 | 平台能力缺失时 P2 blocked，不能靠替换占位图放行 |
| 恢复与成本 | 调用前预留、未知结果对账、受影响依赖失效 | 外部工具无幂等能力时无法保证完全无重复副作用 |
| 抖音图集 | 本地可上传产物与顺序、手机模拟预览 | 不代替实际平台发布入口校验，不自动发布 |
| 开源透明度 | 公私证据分层，公开仅白名单 | 私有真实书测试可审阅但不保证公众能复核其正文 |

## 建议阈值（尚待具体任务契约采纳）

以下为工程/设计建议，不是已测结果，也不是外部平台政策：

| 项目 | 建议起点 | 如何决策 |
| --- | --- | --- |
| 样本 | 自写至少 3 章；长样本须超过单次上下文或强制块上限 | 后续选定样本长度、窗口和模型实际限制，不以固定字数冒充超上下文 |
| 引语 | 常规 12～70 字、长句测至 100 字，另测超容量 | 具体计数字段/标点口径写入契约，不能丢弃长句隐藏失败 |
| 语义审核 | 最终具名台词/实际成品 100% 人工检查 | 不降低为模型自评；候选池允许待审 |
| 三张生图 | 3 独立底图 + 单独人物基准图；至少 2 风格、同人至少 2 张 | 确认数量预算，P3 六风格可按兼容性复用底图但需记录 |
| 风格差异 | 15 对比较，每对五维至少三维实质差异 | 人工 rubric 可调整，但应在生成前确定并保留调整理由 |
| 字号/安全区 | 1080 宽正文 36 px 起；3:4 左右 80、上下 90 px | 实图/字体/手机阅读验证后调整，不作为平台固定安全区 |
| 预览/对比 | 360×480 手机模拟；局部正文对比目标 4.5:1 | 复杂底图以局部和人工审阅为准，非自动可读性保证 |
| 重试 | 每资产初次 + 最多 1 次临时失败重试 | 总调用上限必须另按人物、底图、编辑和重试预留计算；价格未知不估为零 |
| 恢复/修改 | AC-305 五类故障点；AC-306 覆盖全部依赖类别 | 产品实现后用实际调用计数与版本证明，不仅查 JSON 状态 |
