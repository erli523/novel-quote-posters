# V1 架构

应用端负责自然语言任务结构化、逐块语义分析、人物证据、候选评分、调用图像工具与对话审阅；本地包承担确定性处理。脚本不会把基于引号的候选发现冒充模型语义分析。

当前模块：storage 原子落盘/哈希/路径边界；ingest TXT/EPUB→规范正文/章节/段落/窗口；quotes 机械候选发现/精确定位/改写策略；cli 本地交换入口。后续加入 workflow 状态/依赖/预算、layout 六样式、export 审核门禁与打包。

应用端读 chunks.json 对各窗口语义处理，回填人物/候选与依据，再由本地核验。每条引语的 source_hash 与 canonical_hash 都锁定版本；规范正文 Unicode 码点坐标不能当作 EPUB 原始字节偏移。EPUB 用 spine 阅读顺序、正文 XML 文本提取与成员位置映射，不执行脚本、不解压到文件系统。

长文本覆盖分三层：索引范围并集、应用端实际处理窗口记录、人工语义抽查。当前 CLI 只完成索引，semantic_chunks_processed 保持 0；不会根据机械候选数宣传全文语义完成。

审阅对象与资产哈希绑定，更新依赖必须失效。图像用本地持久文件导入，记录真实工具来源；原始小说不进入生成提示词。字体由用户本地提供，记录文件哈希与许可，不分发 Windows 字体。
