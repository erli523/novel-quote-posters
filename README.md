# 小说人物语录海报

从小说中的可追溯原句制作可编辑人物海报。V1 由应用端协调语义分析与真实生图，本地 Python 工具负责解析、核验、中文排字和打包。

**开发中，尚未通过产品验收。** 以 [需求](docs/requirements.md)、[工程规则](rules.md)、[28 项验收标准](docs/acceptance.md) 和 [开发契约](docs/plans/v1.md) 为依据。当前迭代状态见 [开发记录](docs/milestones/progress.md)。

[实际验收状态表](docs/milestones/acceptance-status.md) 分别列出已运行的程序证据和仍待真实图片/人工检查的缺口。离线审核支持人物对照、手机图、裁切模拟及单卡/整组逐项判断；默认不授予任何批准。顺序或卡片版本变化后，旧整组批准不能用于正式导出。

[受控修改](docs/edit-workflow.md) 支持保留原句的显示编辑、已有原句换绑、风格和排序；修改绑定输入版本，冲突拒绝覆盖，换人物清除旧配图指针。

[任务契约](docs/task-contract.md) 固定每次运行的张数、人物/章节/风格、改写与调用总上限及分项额度；缺图或数量不足会报告缺口，不从现有卡片推断用户目标。失败和未知调用仍占额度，各项不能自动互借。

候选补充后可用 prepare-cards --append 续加条目，保留旧 ID、资产及有效审核；分析和配图写入遇到并发修改会拒绝覆盖，重试不调用图片服务。

说话人审核支持完整段落、明确的省略区间和本地整章查看，便于核对插叙及跨段发言；批准绑定上下文版本。困难语料为作者自写预期和 AI 待审提案，不代表一般小说的正确率。

[真实整书测试](docs/real-novel-tests.md) 已使用完整阿Q 9 章及红楼梦 120 回做机器遍历、原句位置和恢复检查，并拒绝章回不齐的儒林外史镜像。阿Q 校对版本已实际读完四个窗口，提交 26 条 AI 语义提案，选出 6 条待审；原句审核页支持只看选中候选，其余条目保持原状态。来源转录警告和其他版本未读语义窗口明确保留，人物归属仍待用户人工判断。[生图排查](docs/image-generation-diagnosis.md) 记录了本地路由证据、项目级配置修复及仍待实际生效验证的部分。

另已取得并测试文库目录所列的儒林外史 56 回版，59 个完整窗口、3,867 个匹配候选的精确位置与原章映射核对完成，应用端语义阅读仍待做。status 会显示来源方框/引号异常观察，全文索引不掩盖转录警告；没有警告也不宣称转录正确或找全语录。真实 EPUB 下载本轮受站点访问错误阻碍，未用自行打包代替外部版本测试。

不需要独立图片 API Key；本地脚本不能直接调用应用端内置生图。用户小说与原始运行数据不进入公开仓库。参考图的几何人物只是布局示意，真实演示须提供工具来源记录。

## 开发环境

Python 3.11+。完整安装、导入、应用端分析交接、排版与导出命令见 [使用说明](docs/usage.md)。推荐独立虚拟环境，运行 `python scripts/check.py` 会保存每次检查证据。代码 MIT；自写虚构样本不是真实小说引文；本机字体不随项目分发。

当前已有分阶段恢复的 TXT/EPUB 导入、原文件与原句核验、增量分析、六套中文布局、增量重排、离线审核、多文件恢复及可独立校验的 ZIP；另有 [图像登记与预算命令](docs/image-workflow.md) 和 status 进度检查。同名人物审核标签用别名区分，困难对白提案仍待人工审核。真实生图累计五次 HTTP 404，重启后第五次 72 毫秒失败，0 张人物图。新聊天启动元数据仍为旧 provider；只读配置诊断与官方实现表明项目配置不能覆盖 model_provider，原项目级修复建议已纠正，生图未恢复。累计保守占用 5/10，剩余 5；新聊天未增加图像调用。真实整书测试契约见 [故障修复与整书测试](docs/plans/image-recovery-real-novels.md)，完整产品验收未完成。六套布局程序的测试通过不能替代六套真实人物样张的视觉验收。
