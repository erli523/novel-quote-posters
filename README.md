# 小说人物语录海报

从小说中的可追溯原句制作可编辑人物海报。V1 由应用端协调语义分析与真实生图，本地 Python 工具负责解析、核验、中文排字和打包。

**开发中，尚未通过产品验收。** 以 [需求](docs/requirements.md)、[工程规则](rules.md)、[28 项验收标准](docs/acceptance.md) 和 [开发契约](docs/plans/v1.md) 为依据。当前迭代状态见 [开发记录](docs/milestones/progress.md)。

不需要独立图片 API Key；本地脚本不能直接调用应用端内置生图。用户小说与原始运行数据不进入公开仓库。参考图的几何人物只是布局示意，真实演示须提供工具来源记录。

## 开发环境

Python 3.11+。完整安装、导入、应用端分析交接、排版与导出命令见 [使用说明](docs/usage.md)。推荐独立虚拟环境，运行 `python scripts/check.py` 会保存每次检查证据。代码 MIT；自写虚构样本不是真实小说引文；本机字体不随项目分发。

当前已有 TXT/EPUB、精确定位、应用端分析导入、六套中文布局、待审核 ZIP、审核门禁，以及独立的状态/预算模块。真实生图工具实测返回 HTTP 404；人物图和完整产品验收未完成。六套布局程序的测试通过不能替代六套真实人物样张的视觉验收。
