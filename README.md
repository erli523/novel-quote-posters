# 小说人物语录海报

从小说中可追溯的连续原句，制作可编辑的人物语录海报。V1由应用端协调语义分析与真实生图，本地Python负责解析、原句核验、中文排字、审阅记录和打包。

**开发中，尚未通过完整产品验收。** 当前三张3:4候选与同句六风格v7均待真实用户审阅；AI检查不能替代人工批准。规范见[需求](docs/requirements.md)、[工程规则](rules.md)、[28项验收标准](docs/acceptance.md)和[实际状态](docs/milestones/acceptance-status.md)。

## 工作流程

1. 导入TXT/EPUB，保留源哈希、章节/段落坐标与窗口覆盖。机器遍历不代表全文语义已读完或精彩语录已找全。
2. 应用端提交人物/原句/归属证据，连续切片逐字核验；人审可查看完整相邻段落及相关整章。精彩程度、说话人和外貌推断保持可审记录。
3. [任务契约](docs/task-contract.md)固定张数、人物/章节/风格、改写政策、尺寸与总/分项调用额度。[图像工作流](docs/image-workflow.md)登记实际工具结果及收据，失败和未知也占额度。
4. 底图与最终中文分层合成，1080×1440 sRGB。等比取景记录裁切；[受控修改](docs/edit-workflow.md)支持显示文字、原句换绑、风格、单卡构图/颜色和排序，旧资产保留，过期计划拒绝覆盖。
5. [六风格样张](docs/style-samples.md)通过显式计划固定同一句、底图、字体与取景，缓存可恢复；[补充审阅](docs/style-review.md)逐套检查并记录15对差异，内容变化使旧记录失效。
6. 私有离线页完成原句归属、单卡和整组本人审阅后，才可正式导出PNG/手机图/出处表/数据/顺序及ZIP。缺批准会拒绝，预览包保留待审标签，不自动上传抖音。

改字/改构图不会自动请求新生图；换人物会清除不兼容配图指针。相同有效结果可复用，损坏/中断保留证据。审核绑定确切内容版本；主审阅和六风格补充记录都绑定前一判断，旧批准不能覆盖后来的否决。

## 开始使用

Python3.11+，安装、应用端分析交接与命令见[使用说明](docs/usage.md)。推荐虚拟环境；`python scripts/check.py`为每次检查保留独立证据。

不需要独立图片API Key；本地脚本不能直接调用应用端内置生图。小说、图像、原始提示词、配置、字体与审核记录默认留本机，公开仅精确白名单通用代码/文档、自写样本和脱敏摘要。代码MIT，自写样本不是现实小说引文；当前V1不提供独立API、无人值守生图或自动社交发布。
